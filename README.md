Neon Heist: an offline web app that turns a person's photo and caption into GTA 6-style cover art — a neon-heist diagonal-split duo poster with a magenta-cyan night grade, bold Anton caption lettering and a Pacifico neon subtitle. Two photo slots with crop and position controls, three night grades, live preview, and one-click export in 1080x1080, 1080x1350 and 1920x1080. Photos never leave the machine. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node main.ts
```
